## 3. 감정 범주 정의와 분석 방법

### 3.1 감정 범주 (8개)

| k | 이름 | 정의 |
|---|---|---|
| sad | 슬픔 | 잃어버림·이별·죽음 앞에서 마음이 아프고 서러운 상태. |
| joy | 기쁨 | 아름다움이나 만족스러운 순간에서 오는 밝고 들뜬 마음. |
| calm | 평온·달관 | 자연이나 삶을 한 걸음 떨어져 담담하고 고요하게 바라보는 마음. |
| hope | 희망·의지 | 시련 속에서도 더 나은 미래를 믿고 앞으로 나아가려는 마음. |
| love | 사랑·헌신 | 대상을 아끼고 그를 위해 자신을 내어 주려는 마음. |
| shame | 성찰·부끄러움 | 자신을 돌아보며 느끼는 부끄러움·괴로움·두려움. |
| long | 그리움 | 곁에 없는 사람·장소·시간을 떠올리며 다시 닿고 싶어 하는 마음. |
| anger | 원망·미움 | 대상이나 처지를 탓하고 미워하며 밀어내려는 마음. |

### 3.2 분석 방법 — 방식 A(감정 사전) + 해석 프로필 결합(hybrid)

1. **전처리:** 본문을 줄바꿈으로 나누고 앞뒤 공백을 지웁니다. 빈 줄은 연 구분으로만 씁니다.
2. **사전 매칭:** 모든 시어를 긴 것부터 정렬해 하나의 정규식으로 만들고(‘성근 별’이 ‘별’보다 먼저), 행마다 범주별 일치 횟수 `c(l,e)`를 셉니다.
3. **사전 비율:** `v_lex(e) = Σ c(l,e) / Σ c(l,e′)`
4. **해석 프로필:** 시마다 반어·역설·상징까지 고려해 정서 강도 `p(e)`(0–1)를 정하고 합계 1로 정규화합니다.
5. **최종 비율:** `v(e) = normalize((1−w)·p̂(e) + w·v_lex(e))`, 기본 w = 40%. 화면의 비율은 최대 잔여법으로 반올림해 합계가 정확히 100%가 되게 표시합니다.
6. **추천:** 최종 벡터끼리 코사인 유사도 상위 3편. **감성 지도:** 공분산 행렬의 상위 고유벡터 2개(거듭제곱법)로 PCA.

### 3.3 감정 사전 수정 내역 (예시 앱 사전 대비)

사전 전체는 `js/data.js`의 `LEX`에 있습니다. 범주마다 15개 이상입니다.

| 범주 | 추가(+) | 삭제(−) | 이유 |
|---|---|---|---|
| sad | 애달, 아프, 쓸쓸, 잃어, 통곡 | — | 새 작품과 입력 시의 상실 표현 보강 |
| joy | 웃음, 웃는, 웃으, 반가, 노래하, 좋으 | 웃 | 한 글자 ‘웃’이 ‘이웃’, ‘웃옷’에도 걸림 → 활용형으로 좁힘 |
| calm | 잔잔, 한적, 한가 | — | 고요함을 뜻하는 형용사 보강 (‘가만히’도 넣었다가 「자화상」 ‘가만히 들여다봅니다’에서 오탐이 나 뺐음) |
| hope | 새벽, 내일, 다짐, 오리라, 이루 | 오는 | ‘오는’은 ‘밀려오는’, ‘찾아오는’ 등 방향만 뜻하는 경우가 많음 |
| love | 어머니, 정다, 품에 | — | 가족애 표현 보강 |
| shame | 뉘우, 참회, 욕되, 욕될, 후회, 부끄럽, 부끄런 | — | 성찰 범주 보강. 「참회록」의 ‘욕될까’, ‘부끄런’과 「길」의 ‘부끄럽게’는 기존 어간 ‘부끄러’로 잡히지 않았음 |
| long | 고향, 아득, 기억, 못 잊, 잊, 그리다, 훗날 | 다시 | ‘다시’는 「광야」의 ‘다시 천고의 뒤에’, 「님의 침묵」의 ‘다시 만날 것을’처럼 희망 문맥이 많음. ‘잊’, ‘그리다’는 「먼 후일」 때문에 추가(검증 사례 6) |
| anger | 원수, 저주, 노여, 억울, 미움 | — | 원망 표현 보강 |

**예외 목록(`STOP`) 신설:** `손님`, `이웃`. 다른 시어를 품고 있지만 감정과 무관한 단어를 먼저 일치시켜 점수에서 뺍니다(검증 사례 5).

수정 효과: ‘다시’를 빼자 「광야」의 사전 기준 그리움이 20% → 15%로 내려가 해석(13%)에 가까워졌습니다.

## 4. 검증 사례 (계산 결과와 해석이 어긋나는 경우)

숫자는 웹앱 **분석 방법 비교·검증** 표의 값입니다(사전만 = w 100%, 해석만 = w 0%).

### 사례 1. 「진달래꽃」 — 반어를 읽지 못함
- **결과:** 사전만 쓰면 원망·미움 38%로 사랑·헌신(38%)과 동률이 됩니다. 해석 프로필에서는 14%입니다.
- **원인:** ‘역겨’가 수미상관으로 두 번, ‘즈려밟’이 한 번 원망으로 잡힙니다. 하지만 ‘역겨워’는 화자가 아니라 임의 마음을 가정한 말이고, ‘즈려밟고’는 원망보다 자기희생에 가깝습니다. 또 ‘죽어도 아니 눈물 흘리오리다’는 부정문인데도 ‘눈물’이 슬픔으로 그냥 세어집니다.
- **개선:** ① 같은 행에 ‘아니’, ‘못’, ‘없이’ 같은 부정어가 있으면 점수를 낮추거나 반어 후보로 표시하기. ② 수미상관처럼 반복되는 연은 한 번만 세는 옵션 두기.

### 사례 2. 「자화상」 — 배경 묘사가 정서를 덮음
- **결과:** 사전만 쓰면 평온·달관 48%로 1위이고, 성찰·부끄러움은 0%입니다. 해석에서는 성찰 23%, 평온 14%입니다.
- **원인:** 1연과 마지막 연에 같은 풍경 묘사(‘달이’, ‘구름’, ‘흐르’, ‘하늘’, ‘바람’, ‘가을’)가 두 번 나와 평온 시어만 12번 잡힙니다. 정작 이 시의 핵심인 자기 성찰은 ‘미워져 → 가엾어 → 그리워’라는 감정의 변화로 드러나서 ‘부끄러’ 같은 시어가 없습니다. 또 ‘돌아갑니다’(걸어서 돌아섬)의 ‘돌아’가 그리움으로 다섯 번 잘못 잡힙니다.
- **개선:** ① 자연 사물 명사(하늘·구름·바람)는 정서 가중치를 0.5로 낮추기. ② ‘돌아가’처럼 이동을 뜻하는 활용형을 예외 목록에 넣기. ③ 행 단위 BERT 분류로 문맥을 반영하기.

### 사례 3. 「서시」 — 상징어를 글자 뜻으로 셈
- **결과:** 사전만 쓰면 평온·달관 33%, 슬픔 20%이고, 희망·의지는 20%입니다. 해석에서는 희망·의지 33%, 슬픔 7%입니다.
- **원인:** ‘죽는 날까지’와 ‘죽어 가는 것을’의 ‘죽’이 슬픔으로 잡히지만, 실제로는 평생의 다짐과 연민을 뜻합니다. ‘하늘’·‘바람’·‘별’은 이 시에서 윤리적 기준·시련·이상을 상징하는데, 사전은 이를 평온의 자연 이미지로만 셉니다.
- **개선:** 작품별로 상징어의 범주를 바꿔 주는 ‘작품 사전(override)’을 두기. 예를 들어 「서시」의 ‘별’ → 희망·의지.

### 사례 4. 「유리창 1」 — 역설의 앞부분만 잡힘
- **결과:** 사전만 쓰면 기쁨이 18%(‘반짝’, ‘황홀’)입니다. 해석에서는 4%입니다. ‘찢어진’ 때문에 원망·미움 9%도 생기지만, 해석상 원망은 없습니다.
- **원인:** ‘외로운 황홀한 심사’는 슬픔 속 순간적 만남을 뜻하는 역설인데 ‘황홀’만 기쁨으로 셉니다. ‘폐혈관이 찢어진’은 아이의 병과 죽음을 말하는 묘사입니다.
- **개선:** 한 구절 안에 서로 반대인 정서 시어가 함께 나오면 ‘역설 후보’로 표시하고 두 점수를 줄이기.

### 사례 5. 「청포도」 — 부분 문자열 오탐(‘손님’ 속 ‘님’)과 개선 결과
- **결과(수정 전):** 사랑·헌신 20%가 나왔는데, 근거 시어는 ‘내가 바라는 **손님**은’의 ‘님’ 하나뿐이었습니다.
- **원인:** 사전이 ‘님’을 부분 문자열로 찾기 때문에 ‘손님’, ‘선생님’ 속 ‘님’도 임(사랑의 대상)으로 셉니다. 이 시의 손님은 기다리는 미래(광복)를 상징해 희망·그리움에 가깝습니다.
- **개선(적용함):** 예외 목록 `STOP`에 ‘손님’을 넣어 먼저 일치시키고 세지 않게 했습니다. 사전 기준 사랑·헌신이 20% → 0%가 되고, 대신 ‘좋으련’(‘좋으’ 추가)이 기쁨으로 잡혀 해석(기쁨 17%)에 가까워졌습니다.

### 사례 6. 「먼 후일」 — 반어를 ‘맞게’ 틀림
- **결과(수정 전):** 사전에 걸린 시어가 ‘믿기지’의 ‘믿’ 하나뿐이어서 희망·의지 100%가 나왔고, 기본 가중치(40%)에서도 지배 정서가 희망·의지로 바뀌었습니다. 해석에서는 그리움이 41%로 가장 큽니다.
- **원인:** 시의 핵심 시어 ‘잊었노라’, ‘그리다가’가 사전의 ‘잊힐’, ‘그리워’와 활용형이 달라 잡히지 않았습니다. ‘믿기지 않아서’는 믿음(희망)이 아니라 이별을 받아들이지 못하는 마음입니다.
- **개선과 남은 문제:** ‘잊’, ‘그리다’를 그리움에 추가하자 사전 기준 그리움 89%로 해석과 같은 방향이 되었습니다. 하지만 ‘잊었노라’(잊었다)를 그리움으로 세는 것은 **결과만 맞고 이유는 틀린** 경우입니다. 이 시는 “잊었다”고 말할수록 못 잊었다는 반어여서 맞은 것이고, 다른 시에서 정말 잊었다는 뜻으로 쓰이면 오탐이 됩니다. 부정·반어를 구분하려면 행 전체의 문맥(‘오늘도 어제도 아니 잊고’)을 보는 모델이 필요합니다.

### 사례 7. 「쉽게 씌어진 시」 — 핵심 정서가 한 번만 나올 때
- **결과:** 사전만 쓰면 슬픔 57%, 성찰·부끄러움 14%입니다. 해석에서는 성찰·부끄러움 35%, 슬픔 27%입니다.
- **원인:** 시의 중심 고백인 ‘부끄러운 일이다’는 한 번만 나오는 반면, ‘슬픈’, ‘잃어버리고’, ‘홀로’, ‘눈물’은 시 곳곳에 흩어져 있습니다. 사전은 빈도만 세므로 주제 구절의 무게를 반영하지 못합니다. 또 ‘눈물과 위안으로 잡는 최초의 악수’의 ‘눈물’은 화해의 눈물인데 슬픔으로 셉니다.
- **개선:** 핵심 구절(`key`)이나 독립된 연에 있는 시어에 가중치를 주거나, 연 단위로 정서를 분류한 뒤 연의 위치(결론부)를 반영하기.

## 5. 한계와 개선 방향

- **부분 문자열 일치의 한계:** 어간 매칭이라 다른 단어 속에 들어 있는 경우(‘이별’ 속 ‘별’ 등)와 부정·반어·역설을 구분하지 못합니다(사례 1, 3, 4). → 형태소 분석기(Kiwi, Okt)로 어간을 정확히 뽑고 부정어 규칙을 추가할 수 있습니다.
- **해석 프로필의 주관성:** 0–1 강도는 제 해석이라 사람마다 다를 수 있습니다. → 여러 사람이 매긴 값을 평균하거나, 해설서 근거를 프로필마다 남기기.
- **반복 구조의 과대 반영:** 후렴과 수미상관이 점수를 부풀립니다(「향수」의 ‘꿈’·‘잊힐’ 각 5회). → 같은 행이 반복되면 한 번만 세는 옵션.
- **작은 사전:** 범주별 16–34개라 처음 보는 시에서는 감지가 적습니다. → 행 단위 BERT(KcELECTRA 등) 분류를 방식 B로 추가해 `data/results.json`과 비교하기.
- **범주 경계:** ‘그리움’과 ‘슬픔’, ‘성찰’과 ‘원망’처럼 겹치는 정서가 있습니다.

## 시 추가 방법

`js/data.js`의 `POEMS` 배열 끝에 있는 주석 예시를 복사해 넣습니다. 필수 필드는 `id, title, poet, year, poetDeath, source, text, theme, interp`입니다. 화면의 편수, 히트맵, 감성 지도, 출처 목록은 자동으로 늘어납니다. 감정 이미지 장면 묘사는 `SCENE_KO`(한국어)와 `SCENE`(영어)에 같은 `id`로 넣으면 됩니다. 없으면 시의 소재로 자동으로 만듭니다.
